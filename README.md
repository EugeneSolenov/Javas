# Реабилитационный центр

Консольная информационная система на Java 17+ для записи пациентов на реабилитацию.

## Запуск PostgreSQL

1. Создайте базу `rehabilitation_center`.
2. Выполните `database/schema.sql`.
3. При необходимости задайте переменные окружения:
   - `REHAB_DB_URL`
   - `REHAB_DB_USER`
   - `REHAB_DB_PASSWORD`
4. Соберите проект: `mvn clean package`.
5. Запустите: `mvn exec:java`.

## Архитектура

`Main` отвечает только за консольный интерфейс, `Service` — за проверки и бизнес-логику, `Repository` — за JDBC-запросы. Основные сущности: `Patient` и `Appointment`; перечисления — `AppointmentStatus` и `RehabilitationType`.

## Бизнес-правила

- ФИО и телефон пациента обязательны.
- Email пациента должен быть корректным и уникальным.
- Пациент для записи должен существовать.
- Длительность занятия — от 15 до 240 минут.
- Один специалист не может иметь две записи на одинаковое время.
- Недопустимые переходы статусов и отменённые записи должны проверяться сервисным слоем.

## База и экспорт

Таблицы `patients` и `appointments` связаны внешним ключом. Для выгрузки предусмотрен CSV-экспорт; зависимость Apache POI в `pom.xml` подготовлена для расширения до XLSX.
