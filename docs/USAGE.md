# Инструкция по демонстрации

## Главное меню

- **Пациенты** — просмотр, добавление и удаление пациентов.
- **Записать пациента на реабилитацию** — создание записи с видом реабилитации, датой, специалистом и длительностью.
- **Поиск** — поиск по ФИО пациента или специалисту.
- **Фильтрация** — по статусу, виду реабилитации и диапазону дат.
- **Статистика** — общее количество записей, распределение по статусам, суммарная длительность и число специалистов.
- **Экспорт** — выгрузка расписания в CSV.

Перед запуском необходимо выполнить SQL-скрипт и настроить PostgreSQL. Если команда `mvn` не найдена, установите JDK 17 и Apache Maven, добавьте их каталоги `bin` в `PATH`, затем повторите `mvn clean package`.
